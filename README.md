# 志愿者优选工作台

上传人员问卷和面试评分，设置小闪电、摄影志愿者的名额，核对后导出完整 Excel 名单。

- **在线使用：** https://turtleneck1109-design.github.io/volunteer-selection/
- **离线使用：** 下载仓库中的 [volunteer-selection-offline.html](https://github.com/turtleneck1109-design/volunteer-selection/releases/latest/download/volunteer-selection-offline.html)，用现代浏览器打开。

## 使用步骤

1. 导入一份或多份人员问卷 `.xlsx`。
2. 导入评分 `.xlsx`，或包含多份评分表的 `.zip`。
3. 设置小闪电与摄影名额、同分规则和重复岗位优先级。
4. 生成名单，在“核对事项”中处理学号差异；可逐人指定岗位或排除。
5. 导出 Excel：摄影、小闪电置顶，普通志愿者按普通面试归一化成绩降序。采用白底、黑色细边框、自动列宽和行高，并冻结表头及前两列。

## 优选规则

- 普通面试默认读取评分表的“归一化成绩”，按数值降序排列（含负数和零），不重新计算。闪电及摄影使用10分原始得分。列名不同可手动映射。
- 缺少普通面试归一化成绩但有有效评分者仍保留，标注并在普通名单中排后；不使用原始总分替代。导出分别保留归一化成绩和15分原始总分，显示最多6位小数，排序与导出数值使用完整精度。
- 同分可全部保留，也可严格按名额截取。严格模式依次比较专项原始分数、普通面试归一化成绩、原名单顺序。
- 重复岗位按设置的优先级依次选人；同一个人只占一个岗位。也可手动调整。
- 未找到有效评分的人员不进入名单。缺少人员问卷的评分记录默认不纳入，可在更多规则中开启。
- 姓名相同而学号不同的记录需人工确认，保留问卷中的学号。
- 数字文本也能正确识别；完整分项与总分冲突时使用分项之和并提示。
- 同一学号多条评分可取平均分、最高分或最后一个有效值。

缺少问卷的人员默认在专项排序前排除，因此结果可能与“先选人、再删除缺少问卷者”的流程不同。

## 数据处理

文件仅在浏览器内存中解析，不上传服务器、不保存到云端。刷新或关闭页面会清空文件和手动调整，请及时导出。仓库仅包含程序、文档和虚构示例，未包含真实人员问卷或评分数据。

支持 `.xlsx` 和包含 `.xlsx` 的 ZIP。旧版 `.xls` 或加密文件需先另存为未加密 `.xlsx`。读取公式缓存及常用评分分项，不执行任意 Excel 公式。

## 本地运行与维护

无需安装依赖或构建，直接打开 `index.html`，或启动静态服务器：

```sh
python3 -m http.server 8000
```

核心逻辑测试与离线版生成需要 Node.js：

```sh
node tests/core.cjs
node scripts/build-offline.cjs
```

GitHub Pages 从 `main` 分支根目录发布。更新源文件后重新生成离线版，再提交并推送。

| 文件 | 用途 |
| --- | --- |
| `core.js` | 身份匹配、分数汇总、配额及岗位分配 |
| `excel.js` | Excel/ZIP 读取与黑边框 Excel 导出 |
| `app.js` | 导入、核对、预览与导出交互 |
| `style.css` | 桌面与移动端样式 |
| `jszip.min.js` | 本地 ZIP 读写依赖 |

JSZip 的许可见 [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md)。
